# Project Onboarding

## Goal

Establish verified repository context before planning or changing code.

## Steps

1. Read `AGENTS.md`, applicable `.github/instructions/`, and the engineering workflow.
2. Inspect root manifests, project settings, installed app registry, URL roots, and current Git status.
3. Inventory each app's models, services, signals/tasks, public routes, migrations, and tests relevant to the request.
4. Identify available test infrastructure and external services without connecting to production.
5. Confirm frontend assets/build tooling and compare them with the approved hybrid design direction in `docs/05-frontend/design-system.md`.
6. Record facts, unknowns, and any required owner approval before implementation.

## Output

Provide a concise inventory and validation plan. Do not create a new report file unless requested.
